# Target Type Notes

This folder contains cleaned notes for this target type.

Each note should explain:
- status
- label
- what the contract or module does
- which functions were checked
- what risk areas were reviewed
- what was verified
- what was killed
- what was learned
- whether the finding was alive, killed, or only educational

Only cleaned notes should be added here.

> Disclaimer: These are educational security notes, not full audits.
