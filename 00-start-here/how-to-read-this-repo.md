# How To Read This Repo

This repo is a smart contract security portfolio.

Start with:
1. `best-work/` for the strongest examples
2. `01-bug-patterns/` for vulnerability patterns
3. `02-safe-vs-unsafe/` for secure design comparisons
4. `03-proof-artifacts/` for proof notes
5. `04-sample-reports/` for report-style examples
6. `05-real-target-notes/` for real-code review notes
7. `06-false-positive-lessons/` for verification discipline

Raw practice notes stay private. Public work is cleaned and proof-focused.
